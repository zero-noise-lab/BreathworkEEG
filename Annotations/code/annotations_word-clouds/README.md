# Word-cloud analysis of cued-recall transcripts (breathwork sessions)

Code for the word-cloud figures of the manuscript.
Methods, results and limitations are described in the manuscript.

> **Synthetic data only.** The original transcripts, questionnaire data and participant IDs cannot be shared (participant privacy). This repository contains a synthetic stand-in dataset with the same file structure and columns, generated by `make_synthetic_data.py` (fixed seed). Text is random words, questionnaire values are random numbers. **Outputs from this data have no scientific meaning**; they only show that the pipeline runs end to end.

## Contents

```
code/annotations_word-clouds/
├── script_word-clouds.ipynb              # word-cloud analysis
└── pipeline_transcript_extraction/       # creates transcripts_bw.csv (not runnable here)
make_synthetic_data.py                    # generator for the synthetic input files
input/synthetic/data_annotations/         # synthetic transcripts, questionnaire and phase files
```

## Run

1. `pip install -r requirements.txt` (NLTK resources are downloaded on first run)
2. The synthetic data is already included. To regenerate it: `python make_synthetic_data.py --force`
3. Run `script_word-clouds.ipynb` from top to bottom. Figures are written to `output/wordclouds/`.

Cells adapted for the synthetic data are marked `NOTE (synthetic data)` (cells 1, 6 and 10: excluded IDs, input path, expected participant list). The analysis logic is unchanged.

## Input files

| File | Columns used | Purpose |
|---|---|---|
| `transcripts_bw.csv` | `person_id`, `frame`, `text`, `quality_warnings`, `filter_tag` | Transcript chunks; frame = timestamp × 50 FPS |
| `ASC_all.csv` | `session`, `subject`, `meq_total` | MEQ-30 total score for the tertile split (session `BW`) |
| `session_phases/<ID>/phase_intervals.csv` | `face_id`, `phase`, `start_frame`, `end_frame` | Phase boundaries per participant |

## Transcript extraction (`pipeline_transcript_extraction/`)

Code that produced `transcripts_bw.csv` from manually corrected Whisper output (Whisper large-v3 via [Jain, 2024](https://github.com/Namsjain01/breathwork-transcription)). It reads chunk files of the form `<data-root>/<person_id>/<BW|PMR>/video_*/transcripts/transcripts_c*/*.txt` (header `[VIDEO TIMESTAMP: HH:MM:SS.fff][QUALITY WARNINGS: ...]`, optional coding tag, text) and writes one table with `frame = round(timestamp_s × 50)`. It is run via SLURM (`run_pipeline.sh`) on the university cluster and is included for transparency only, because the raw files contain participant data.
